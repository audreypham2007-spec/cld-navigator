# CLD Navigator

A support tool for speech-language pathologists (SLPs) assessing bilingual
children, especially children who speak languages with few published tests.

## Why I built this
[Bilingual children who speak less-common
languages often get misidentified with speech disorders. I know, because I was one of them. I spoke Vietnamese only at home, and when I started going to an American public school, my words were jumbled up. I want to make sure that SLPs have appropriate resources to make the best decisions for their clientele.]

## What it does
- Saves case information using a code, never a child's name
- Shows "things to consider" about each child's language exposure
- Collects research notes on assessing different languages
- Always reminds the SLP that they make the clinical decisions

## What it does NOT do
It does not diagnose and is not a test. It has not been validated with real
clinicians or cases.

## Built with
Python, Streamlit, SQLAlchemy, SQLite
